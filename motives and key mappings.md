## Navigation Controls

| Action              | Computer Key | Music Keyboard Key          | Comments              |
|---------------------|--------------|-----------------------------|-----------------------|
| Next scene          | → arrow      | C4 (note 60) or C5 (note 72) | Pitch wheel above 75% |
| Previous scene      | ← arrow      | B3 (note 59)                | Pitch wheel below 25% |
| Fade in             | F            | Knob 8 above halfway        |                       |
| Fade out            | G            | Knob 8 below halfway        |                       |
| Start performance   | Enter        | Any key / Knob 1 above half | Initial load only     |
